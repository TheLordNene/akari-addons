# AKARI Add-ons für Home Assistant

## AKARI-Brücke

Verbindet Home Assistant mit [AKARI](https://akari.lucidian.dev), ohne Tunnel und ohne
Portfreigabe. Anleitung: [akari-bridge/DOCS.md](akari-bridge/DOCS.md)

### Installieren

[![Repository in Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FTheLordNene%2Fakari-addons)

Oder von Hand: Home Assistant → Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories →
`https://github.com/TheLordNene/akari-addons` hinzufügen. Danach erscheint „AKARI-Brücke“ im Store.
